# Deadlock Compare

Overlay and isolate Deadlock post-match graphs. Built to load inside the game through a Panorama mod (Compare button on the post-match screen), and also works in a normal browser.

Open `index.html?match=<match id>`.

- Click heroes to show or hide them. Ctrl+Click shows only that hero.
- Player-specific graphs (Damage breakdown, Souls by source, Support value, Kills by type) overlay any number of players: color = player, line style = category.
- With exactly 2 players on a general graph, "Difference" shows one minus the other.
- View As on the General graphs: Value, Per Minute, % of Team (each hero's share of their team), Teams (six heroes added together) and Lanes (each lane pair added together).
- Power graphs show item purchases under the lines for 1 to 3 heroes; hovering lists what was bought since the last point.
- Matchups tab: hero damage, hard crowd control and slows between every pair of opponents, from Valve's damage matrix, with a head-to-head for any pair. Totals match the scoreboard's hero damage exactly. Crowd control values are milliseconds (whole 1/64 s ticks).
- MVP tab: our Experimental score, plus Valve's own accolades for the picked hero with the lobby best for each.

Optional URL parameters: `graph=<id>` (for example `souls_lead`), `players=<slot,slot>`, `embed=1` (in-game overlay mode: ESC asks the game to close it).

Data: [deadlock-api](https://deadlock-api.com/) `/v1/matches/{id}/metadata`. Hero names come from the game's own files (`heroes.js`).

Local test without the API: `python -m http.server`, then `index.html?match=136014932&src=test/match_136014932.json`. Add `tab=matchups` or `tab=mvp` to open another tab.

## Game data

`gamedata.js` (item, accolade and damage source names) and `assets/items/` (item icons) are generated by `tools/build_gamedata.py` from the game's `abilities.vdata_c`, `accolades.vdata_c`, localization files and item images (the raw files are in `raw/ranks_items_raw.zip` on the `assets-portraits-raw` branch). `tools/kv3.py` reads the binary KV3 format, ported from [ValveResourceFormat](https://github.com/ValveResourceFormat/ValveResourceFormat) (MIT). Item ids in match data are MurmurHash2 (seed `0x31415926`) of the item's class name.

## Game assets

`assets/` holds hero portraits (the painted `<hero>_card_psd` art masked with `hero_badges/hero_image_mask_psd`, as on the native graph screen), the post-game background, icons and Deadlock's UI fonts (Radiance, VALVE Oracle, VALVE Pulp, subset to Latin), extracted from the game files with `tools/extract_assets.py` and decoded with `tools/s2decode.py`. They are Valve's. The fonts' license says: "Like other Valve game content, you may use this font to create Fan Art, as described in the Steam Subscriber Agreement." This project is a free, non-commercial fan mod.
