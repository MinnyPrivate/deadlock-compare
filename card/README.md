# Postmortem simple card

Open `card-lab.html` straight from disk (no server) to see every state. It is a dev page and is not in the `.assetsignore` allowlist, so it never goes live.

- `card.js`: `PMCard.render(data)`, `PMCard.renderBack()`, `PMCard.enableTilt(container)`. The rarity ladder and damage levels are documented at the top.
- `card.css`: palette, type, engraving styles. Engraving lives in shared `<symbol>`s, so style it through the `--e-*` custom properties, not selectors.
- `art.js`: generated by `node tools/build_card_art.mjs` from `card/src/` (hero silhouettes, the game's suit icons, the logo).
- Swap the logo: replace `card/src/logo.svg` (single colour, `currentColor`) and rerun the build script.
- New hero silhouette: export the hero card render, run `tools/trace_hero_silhouette.py` on it, save as `card/src/hero_<id>.svg`, rerun the build. Pass `eyes: false` to hide Haze-style eye cut-outs.
- Fonts: Bodoni Moda (SIL OFL, `assets/fonts/BODONI-MODA-OFL.txt`) for numbers and flavor lines, VALVE Pulp for the engraved caps labels.
