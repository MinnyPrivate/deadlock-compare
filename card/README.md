# Postmortem simple card

Open `card-lab.html` straight from disk (no server) to see every state. It is a dev page and is not in the `.assetsignore` allowlist, so it never goes live.

- `card.js`: `PMCard.render(data)`, `PMCard.renderBack()`, `PMCard.deal(card)`, `PMCard.enableTilt(container)`. The rarity ladder, suits and damage levels are documented at the top.
- Data: `{ rarity, suit, hero, heroName, value, stat, no, of = 1000, newBest, bad, eyes, layout: 'pip' | 'cameo' }`. `no` is the rank among `of` comparable games ("No. 9 of 1,000 Haze games").
- The suit sets the ink (`--suit`, `--suit-deep`, `--suit-hi` on `.s-<suit>`) and the big pip; the rarity sets the frame and the paper. Crown is printed in brass, Joker is a misprint.
- `NEW BEST` is the only stamp. Legendary's ink bleed is driven from script in `deal()`, because Chromium does not repaint a backdrop filter under a CSS-animated mask.
- `card.css`: palette, type, engraving styles. Engraving lives in shared `<symbol>`s, so style it through the `--e-*` custom properties, not selectors.
- `art.js`: generated by `node tools/build_card_art.mjs` from `card/src/` (hero silhouettes, the game's suit icons, the logo).
- Swap the logo: replace `card/src/logo.svg` (single colour, `currentColor`) and rerun the build script.
- New suit icon: save a flat single-colour SVG as `card/src/suit_<name>.svg` and rerun the build.
- New hero silhouette: export the hero card render, run `tools/trace_hero_silhouette.py` on it, save as `card/src/hero_<id>.svg`, rerun the build. Pass `eyes: false` to hide Haze-style eye cut-outs.
- Fonts: Bodoni Moda (SIL OFL, `assets/fonts/BODONI-MODA-OFL.txt`) for numbers and the serial line, VALVE Pulp for the engraved caps labels.
